# Recommended PR actions

## Steps
1. Gather the picture as in exec-summary (stats_overview, topics_hot, posts_search) and the risks as in
   risk-complaints (negative and accuse/crisis posts).
2. Derive actions from evidence only: each action must point to specific posts or numbers.
3. Prioritise by impact and urgency.

## Output
- One line: scope and dates.
- A numbered list, highest priority first. Each: **行動** (one sentence), **原因** (the evidence, with links and
  numbers), **時間** (now / this week / ongoing), **風險** (what could go wrong).
- Never recommend actions the data doesn't support; say so if the data is thin.
- Under every figure taken from stats_overview, authors_top, sources_top or trend (counts, sentiment index, scores,
  rankings), one line: 「這些數字取決於我們追蹤哪些來源和關鍵字，未必反映實際情況。」 (in English: "These figures depend on which sources and keywords YYC follows,
  so they may not reflect what is actually happening.")
