# Every Secret of the YYC cluster `yyc` that lives in git, and the store `yyc` keys its values come from.
# infra/seal.py reads this to (re)seal a Secret: values from the env (a session holding the store `yyc`), sealed to
# infra/sealed-secrets.pem, written as a SealedSecret to FILE. The store is the only copy outside the cluster: a value
# that isn't a store key can't be rebuilt, so a new Secret value goes into the store first (jarvis2 put-key yyc ...).
#
# NAMESPACE/NAME  TYPE  FILE  KEY=STORE_KEY ...      (STORE_KEY+nl: the store value followed by one newline)
#                                                    ('text': that literal text, not a store key)
#                                                    (A|B?: "<A>,<B>", the parts joined by commas; a trailing ? makes a
#                                                     part optional, skipped when the env lacks it: a callee accepting
#                                                     the current and the next pair token during a rotation)
# NAMESPACE/NAME@talos: the same Secret name on the new Talos cluster, where another line names it on the old one.
# Two clusters (yyc-ai/refactor DESIGN 15.9): seal.py picks the cert by FILE's folder (its CERTS table): the new
# cluster's folders get infra/sealed-secrets-talos.pem, every other folder infra/sealed-secrets.pem.
